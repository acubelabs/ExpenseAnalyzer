About Expense Analyzer

Expense Analyzer is a native Android application engineered with Jetpack Compose, Material Design 3, and dynamic Room Database storage. Unlike traditional finance tools, Expense Analyzer prioritizes user privacy—processing data locally whenever possible and storing encrypted backups directly in the user's private Google Drive storage.
