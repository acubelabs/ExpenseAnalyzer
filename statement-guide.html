Official Parser Documentation

Supporting Documents & Statement Upload Guide

Learn how Expense Analyzer automatically scans digital PDF bank statements and Excel spreadsheets, detects table structures, handles 40+ date formats, and rejects non-financial records.

Supported File Formats

Expense Analyzer processes financial statements in the following native digital document formats:

PDF Documents (`.pdf`)

Digital bank and credit card statements containing a readable embedded text layer. Encrypted/password-protected PDFs are fully supported (the app prompts for the statement password upon upload).

Excel Spreadsheets (`.xlsx`, `.xls`)

Modern and legacy Microsoft Excel spreadsheets exported from net banking portals, credit card dashboards, or accounting software.

Automated Table Scanning: The parser scans up to the first 100 rows of any uploaded document to automatically identify transaction table headers, skipping bank logos, branch addresses, and customer metadata.

Recognized Column Headers

The statement parser automatically maps transaction columns using weighted keyword matching across the following categories:

Column Type Recognized Keyword Headers
Date Column `Date`, `Txn Date`, `Tran Date`, `Transaction Date`, `Value Date`, `Posting Date`, `Post Date`, `Date & Time`, `Date/Time`
Narration / Description `Description`, `Narration`, `Particulars`, `Transaction Details`, `Txn Details`, `Remarks`, `Note`, `Memo`, `Details`, `Paid To`, `Received From`, `Payee`, `Payer`, `Beneficiary`
Unified Amount Column `Amount`, `Txn Amount`, `Transaction Amount`, `Amt`, `Value`, `INR`, `USD`, `EUR`
Debit / Withdrawal Column `Debit`, `Withdrawal`, `Expense`, `Paid Out`, `Out`, `Spent`, `Dr`
Credit / Deposit Column `Credit`, `Deposit`, `Paid In`, `Income`, `In`, `Received`, `Cr`
Type / Indicator Column `Type`, `Txn Type`, `Transaction Type`, `Dr/Cr`, `Debit/Credit`
Balance Column (Metadata) `Balance`, `Closing Balance`, `Bal`

Supported Date Formats (Over 40 Variations)

Expense Analyzer seamlessly handles short/long year variations, month names, timestamps, and raw numeric serial dates:

Date Category Format Specification Example String
Standard Numeric `dd/MM/yyyy`, `dd-MM-yyyy`, `dd.MM.yyyy` `01/08/2026`, `01-08-2026`, `01.08.2026`
ISO & US Layouts `yyyy-MM-dd`, `MM/dd/yyyy` `2026-08-01`, `08/01/2026`
Short Year Variations `dd/MM/yy`, `dd-MM-yy`, `dd.MM.yy` `01/08/26`, `01-08-26`
Month Name Formats `dd MMM yyyy`, `dd-MMM-yyyy`, `MMM dd, yyyy` `01 Aug 2026`, `01-Aug-2026`, `Aug 01, 2026`
Formats with Timestamps `yyyy-MM-dd HH:mm:ss`, `dd MMM yyyy hh:mm a` `2026-08-01 14:30:00`, `01 Aug 2026 05:14 PM`
Excel Serial Timestamps Raw numeric serial timestamps in Excel `46113` or `46113.0` (Days since 1900-01-01)

Document Rejection Criteria

To preserve financial data integrity, documents meeting any of the following conditions are automatically rejected:

  • 1. Non-English / Foreign Script Documents: Statements containing non-Latin scripts (e.g. Tamil, Devanagari/Hindi, Telugu, Malayalam, Arabic, Chinese).
  • 2. Non-Bank Utility, Medical & Service Invoices: Hospital bills, electricity invoices, broadband/fiber bills, school fee receipts, property tax notices, PNR/flight tickets, and e-commerce orders.
  • 3. Scanned PDF Images without Text Layer: Image-only paper scans lacking an embedded digital vector text layer.
  • 4. Encrypted PDF without Password: Password-protected files where the user cancels the prompt or inputs an invalid password.
  • 5. Missing Core Columns: Documents where neither a Date nor a Narration column can be located within the first 100 rows.
  • 6. Summary-Only Certificates: Bank cover letters or balance certificates containing opening/closing balance summaries but zero individual transaction line items.
