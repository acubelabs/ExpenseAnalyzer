Multi-Tenant Engineering

Physical Multi-Tenant Database Isolation

How Expense Analyzer isolates financial records when multiple users share a tablet or phone.

The Multi-Tenant Isolation Flow

  1. Google Sign-In Trigger: Google Auth is used solely to derive a unique user identifier string.
  2. Database Resolution: The app creates/opens `expense_analyzer_{userId}.db` inside the device's protected internal app directory.
  3. Physical Database Lock: When User A active, User B's SQLite file is fully closed with zero active file handles.
  4. Sign-Out Protocol: Signing out flushes SQLite WAL logs and completely revokes memory pointers before switching profiles.
Comprehensive Capabilities

Detailed Feature Matrix

Multi-Bank Consolidation

Consolidate statements from major Indian and global banks (HDFC, SBI, ICICI, Axis, Kotak, Citi, HSBC) alongside mobile wallets (Paytm, PhonePe, GPay).

PDF & Excel Parser Engine

Auto-detects transaction tables across PDF files (with password decryption support) and `.xlsx`/`.xls` spreadsheets without manual row formatting.

OpenCV & ML Kit Receipt Scanner

Scan paper receipts using interactive quadrilateral crop overlay, Sauvola thresholding, illumination correction, and ML Kit text recognition.

Smart Rule & Category Engine

Auto-categorize transactions into 13 default categories (Food, Travel, Bills, Shopping, Investments, etc.) with custom keyword rules and learned memory.

Lend & Owe Debt Tracker

Track informal loans, split bills, and borrowed amounts with contacts, partial settlements, settlement history, and scheduled reminder alarms.

Encrypted Drive Backup & Export

Export financial data into formatted Excel spreadsheets or PDF reports, and maintain automated encrypted backups directly in your private Google Drive folder.
